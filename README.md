# Emergency-Department-Patient-Flow-Simulation-Capacity-Optimization
Developed a discrete-event simulation of emergency department patient flow using AnyLogic Process Modeling Library, modeling triage, acuity-based routing, physician examination, diagnostics, admission, discharge, and inpatient stay.
Performed parameter-variation experiments across ED beds, doctors, triage nurses, fast-track rooms, and inpatient beds to evaluate resource utilization and patient length of stay.
Identified capacity thresholds and diminishing-return regions through KPI analysis, including overall LOS, admitted-patient LOS, fast-track LOS, and resource utilization.
Technologies: AnyLogic, Discrete-Event Simulation, Process Modeling, Queueing Systems, Parameter Variation, Statistical Analysis
